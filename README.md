# Souyan Portfolio

Modern responsive developer portfolio.

### Features
- Rounded glassmorphism UI
- Bold typography
- Blue gradient accent
- Dark/light theme switcher with localStorage persistence
- GSAP entrance and scroll animations
- Cursor glow
- Magnetic buttons
- Project card tilt interaction
- Responsive mobile layout
- Reduced-motion accessibility support

### Structure
- `index.html`
- `styles/style.css`
- `js/app.js`
